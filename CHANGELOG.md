# CozyMuseum Design System Releases

## 1.0.0 - 2026-08-31

- Establish Global, Alias, and Component token tiers with one-way dependencies.
- Publish CSS, SCSS, JavaScript, and JSON exports from one Style Dictionary source.
- Govern Quiet Glass, navigation, button, and card component contracts without owning product runtime.
- Align Games with Aquarium and Film with Flora through shared accent and background-overlay contracts.
- Keep Social and Music treatments independent while preserving the established tab order and assets.
- Add pull-request CI for deterministic builds, package cleanroom, token policy, and publication integrity.
- Preserve the 35-file byte-addressed publication consumed by CozyMuseum without changing runtime UX/UI.
